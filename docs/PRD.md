# 产品需求

## 定位

Personal Agent 是运行在个人 Windows 电脑上的本地优先助手。它通过可配置的大模型进行对话，能持续了解用户、通过扩展获得新能力，并由多个职责清晰的 Agent 协作处理问题。

优先价值是长期记忆与陪伴感，同时必须具备可靠执行和可扩展性。打开应用直接进入个人对话，可切换群聊、任务和插件管理。

## 用户与边界

- 首期用户：单人自用；未来以 Apache-2.0 开源，不做注册、计费、多租户或运营后台。
- 首期运行：Windows，本地 Node 服务 + 浏览器 UI。
- 模型：用户配置的外部 API，包括 OpenAI 兼容、Anthropic、DeepSeek；首期不要求本地模型。
- 数据：会话、记忆、Agent、插件配置默认保存在本机；外发内容仅限模型请求和用户明确授权的工具调用。
- QQ/AstrBot、云端常驻、多设备同步、主动消息和公开插件托管市场不阻塞首个可用版本。

## 核心流程

1. 用户配置 Provider，创建或选择个人 Agent，进行流式对话。
2. 对话结束后由记忆引擎生成候选；候选在 UI 中可查看、修改、确认或删除，敏感内容默认不自动固化。
3. 用户切换到群聊，可 @ 一个或多个 Agent；被点名 Agent 可按需请求其他 Agent 协作。
4. 用户从 Git 仓库安装插件，查看其能力和权限，确认后启用；插件可贡献工具、Agent 模板和声明式工作流。
5. 工具执行前由权限策略检查资源范围；需要审批的副作用操作由用户确认，执行过程可追踪。

## MVP 成功标准

- 用户可以通过模型 API 完成可恢复的流式对话。
- 用户可以管理记忆候选，看到来源并纠正或删除错误记忆。
- 至少三个可配置 Agent 能通过点名和自动协作完成一次群聊任务，且无无限循环。
- 一个 TypeScript 示例插件可从 Git 安装、查看权限、启用、调用、禁用、更新和回滚。
- 文件和命令工具按授权范围执行，越权操作被拒绝并记录。
