# Personal Agent

本项目计划构建一款本地优先的个人助手：具备跨会话记忆、可安装扩展、多 Agent 群聊和受控的本地执行能力。产品服务个人使用，未来开源；首版不包含账号、计费和多租户。

开发必须遵循 [AGENTS.md](AGENTS.md)，产品与阶段范围见 [项目需求](docs/PRD.md) 和 [路线图](docs/ROADMAP.md)。

## 核心原则

- 先复用经过验证的开源实现，再写必要的适配代码；不重造 agent loop、上下文压缩、记忆引擎、MCP 或浏览器自动化。
- 优先依赖上游包或服务；只有接口不满足需求时才维护最小补丁，并保留上游来源、版本、许可证和回合并策略。
- 产品差异集中在个人助手体验、Agent 群聊、插件管理、记忆呈现和安全权限。
- 默认本地运行，用户数据和密钥留在本机；模型请求只发送到用户配置的 Provider。
- 第三方插件独立进程运行，默认无权限，按资源范围授权。

## 当前状态

当前仓库从空工作区开始。已有原型位于 `E:/dsh-data/personal-agent`，其中 `agent/` 有 agent loop、群聊、@ 解析、工具和 JSONL 存储；`server/` 有通知分诊原型。迁移前必须逐项检查依赖、测试、许可证和实现质量，不整体复制目录。
